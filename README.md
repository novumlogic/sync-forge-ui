# sync-forge-ui

This repo contains the UI for the Sync Forge project.

### Getting Started

- Clone the repo
- Set up the environment variables in `.env.local`
- Run `pnpm install`
- Run `pnpm dev`
- Open `http://localhost:5173` in your browser

> Note: You will need to have [pnpm](https://pnpm.io/) installed.

#### Environment Variables
`VITE_API_BASE_URL`: The URL on which the Sync Forge API is running.

> Template .env.local file is available [here](env.template)
